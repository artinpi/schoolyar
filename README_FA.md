# مدرسه‌یار آنلاین — نسخهٔ آمادهٔ پیکربندی

مدرسه‌یار یک وب‌اپ فارسی راست‌چین با امکان بسته‌بندی برای اندروید است. این بسته شامل رابط ورود، راه‌اندازی امن مدیر اصلی، ساخت حساب معلم/دانش‌آموز توسط مدیر، تکالیف، اطلاعیه‌ها، کد Cloud Functions و قوانین پایهٔ Firestore است.

## وضعیت واقعی پروژه
- رابط ورود و پنل‌ها: پیاده‌سازی شده.
- نقش‌ها: مدیر، معلم و دانش‌آموز؛ انتخاب نقش از صفحهٔ ورود ممکن نیست.
- ساخت اولین مدیر: با کد راه‌اندازی ذخیره‌شده در Secret سرور.
- ساخت حساب معلم/دانش‌آموز: از پنل مدیر و با Cloud Function امن.
- تکالیف و اطلاعیه‌ها: ذخیره و خواندن آنلاین از Firestore پس از پیکربندی.
- پیام‌رسان خصوصی: گفتگو با نام کاربری، فهرست گفتگوها و ارسال/دریافت زنده پیام‌ها؛ نیازمند انتشار Cloud Function و قوانین جدید Firestore.
- اتصال به پروژهٔ Firebase شما: هنوز باید شناسه‌ها و Secret واقعی را وارد کنید.
- APK نهایی: در این بسته ساخته نشده؛ ساخت APK به Android SDK و محیط اندروید نیاز دارد.
- نمره‌دهی، حضور و غیاب و مدیریت کلاس‌ها هنوز در این نسخه پیاده‌سازی نشده‌اند. پیام‌رسان خصوصی پیاده‌سازی شده اما تا زمان اتصال به Firebase و انتشار توابع/قوانین، آنلاین کار نخواهد کرد.

## پیش‌نیازها
Node.js 20 یا جدیدتر، حساب Firebase، Firebase CLI و برای APK، Android Studio همراه Android SDK.

## راه‌اندازی آنلاین
۱. در Firebase Console یک پروژه بسازید و Web App، Authentication با روش Email/Password و Cloud Firestore را فعال کنید.
۲. تنظیمات Web App را در `www/firebase-config.js` وارد کنید. این مقادیر عمومی‌اند؛ کلید Admin SDK را اینجا نگذارید.
۳. فایل `.firebaserc.example` را به `.firebaserc` تغییر دهید و `YOUR_PROJECT_ID` را با شناسهٔ پروژه جایگزین کنید.
۴. در ریشهٔ پروژه اجرا کنید:

```bash
npm install
npx firebase-tools login
npx firebase-tools functions:secrets:set BOOTSTRAP_SECRET
```

برای `BOOTSTRAP_SECRET` یک مقدار طولانی و تصادفی انتخاب کنید و آن را فقط در اختیار مدیر/مسئول فنی قرار دهید؛ آن را در فایل‌های وب، گیت یا پیام عمومی ننویسید.

۵. توابع سرور و قوانین پایگاه داده را منتشر کنید:

```bash
npx firebase-tools deploy --only functions,firestore:rules
```

۶. وب‌اپ را منتشر کنید:

```bash
npx firebase-tools deploy --only hosting
```

۷. در Firebase Console > Authentication > Settings، دامنهٔ Hosting منتشرشده را در Authorized domains بررسی کنید. سپس صفحه را باز کنید و از «راه‌اندازی اولیه مدیر» حساب مدیر را بسازید. این مرحله فقط یک‌بار مجاز است.

## ورود با نام کاربری
Firebase به‌صورت پیش‌فرض ایمیل/رمز عبور می‌خواهد. این برنامه نام کاربری را در سمت برنامه به ایمیل داخلی با دامنهٔ `madreseyar.app` تبدیل می‌کند. کاربران را فقط از طریق فرم ساخت حساب در پنل مدیر بسازید؛ حساب‌های دستی با روش دیگری ممکن است با ورود برنامه سازگار نباشند.

## ساخت APK اندروید
پس از پیکربندی Firebase و نصب Android Studio/SDK:

```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```

در Android Studio گزینهٔ **Build > Build Bundle(s) / APK(s) > Build APK(s)** را انتخاب کنید. اگر پوشهٔ `android` از قبل ساخته شده باشد، دستور `cap add android` را دوباره اجرا نکنید؛ از `npx cap sync android` استفاده کنید.

## امنیت مهم
- هرگز کلید خصوصی Admin SDK را در اپ قرار ندهید.
- مدیر را فقط با Secret راه‌اندازی اولیه بسازید؛ Secret را پس از راه‌اندازی در محیط امن نگه دارید و در صورت نیاز چرخش/ابطال کنید.
- قبل از استفاده با داده‌های واقعی، قواعد دسترسی، بازیابی رمز، پشتیبان‌گیری، سیاست حریم خصوصی و الزامات مدرسه را بازبینی کنید.
- نسخهٔ فعلی یک MVP است؛ امکانات نمرات، حضور و غیاب و مدیریت کلاس‌ها در این نسخه موجود نیستند. پیام‌رسان خصوصی نیازمند پیکربندی و انتشار Firebase است.

## پیام‌رسان داخلی
- از منوی «پیام‌رسان داخلی» گزینهٔ «گفتگوی جدید» را بزنید و نام کاربری طرف مقابل را وارد کنید.
- گفتگوها خصوصی‌اند؛ خواندن گفتگو و پیام‌ها فقط برای دو عضو آن مجاز است. ساخت گفتگو از Cloud Function انجام می‌شود تا فهرست کاربران در کلاینت افشا نشود.
- برای فعال‌سازی نسخهٔ فعلی، پس از تنظیم Firebase اجرا کنید: `npx firebase-tools deploy --only functions,firestore:rules`.
- این MVP هنوز وضعیت خوانده‌شدن، اعلان پوش، ارسال تصویر/فایل، مسدودسازی و گزارش تخلف را ندارد.

## باز کردن در Android Studio
من نمی‌توانم از این گفتگو به Android Studio روی دستگاه شما وصل شوم یا دکمه‌های آن را کنترل کنم. بعد از نصب Node.js و Android Studio، در پوشهٔ پروژه اجرا کنید: `npm install` سپس `npx cap add android` (فقط اگر پوشهٔ android وجود ندارد)، بعد `npx cap sync android` و `npx cap open android`. در Android Studio از منوی Build، گزینهٔ Build APK(s) را انتخاب کنید.
